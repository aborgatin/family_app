# Skills

Claude Code loads every folder here as a skill for sessions opened in this repo. How they fit
together: [`docs/agents/agentic-workflow.md`](../../docs/agents/agentic-workflow.md).

Most skills are based on [mattpocock/skills](https://github.com/mattpocock/skills), used under the
MIT License (copy in [`LICENSE-mattpocock-skills`](LICENSE-mattpocock-skills)), and adapted for
this repo (e.g. the usage budget in `implement-spec`).
